# Sheet-metal materials — density and handling

Densities below are **nominal textbook values**, rounded. They are a starting point, not a certificate value.
For any mass that goes into a drawing, quotation or shipping document, take density from the
supplier's material certificate / datasheet or from the company material library, and record which one.

| Material (common designation) | Nominal density, kg/m³ (= g/cm³ x 1000) | Note |
|---|---|---|
| Carbon steel (S235/S355, DC01) | ~7850 | |
| Stainless steel 304 / 1.4301 | ~7900-8000 | varies by source |
| Stainless steel 316 / 1.4401 | ~8000 | varies by source |
| Aluminium EN AW-5754 | ~2660-2670 | alloy datasheets differ slightly |
| Aluminium EN AW-5052 | ~2680 | |
| Aluminium EN AW-6061 | ~2700 | |
| Copper (Cu-ETP) | ~8900-8960 | |
| Brass (CuZn37) | ~8400-8500 | |
| Galvanised steel sheet | ~7850 (+ coating) | zinc coating adds a small mass; not in base density |

## Rules
- Write the alloy, temper and product form (sheet/plate/coil) next to any density you use.
- Nominal thickness is not actual thickness: sheet is supplied within a thickness tolerance; for a mass check, state which one you used.
- Coatings (zinc, powder paint), weld metal, hardware and gaskets are separate mass items.
- A CAD mass equals volume x the density of the material assigned in the model. If the assigned material is wrong or its density was edited, the mass is wrong.
- Mechanical properties (yield, tensile, hardness) depend on temper and standard; never quote them without the standard and temper.

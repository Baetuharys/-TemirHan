# Evidence labels (use in every technical or commercial answer)

| Label | Meaning |
|---|---|
| SUPPLIED | the user or a document gave this value |
| CALCULATED | derived from other values with the formula shown |
| SOURCE-BACKED | taken from a named source (standard, datasheet, certificate) with edition/date |
| PRACTICE | common engineering/shop practice; shop- or company-dependent |
| ASSUMED | a stated guess made to continue; replace when possible |
| ESTIMATED | an approximate value with an error range |
| UNKNOWN | not available; ask or mark as release blocker |

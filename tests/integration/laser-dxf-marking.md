# Test: Laser DXF Marking

## Input
The user needs stud locations visible in a laser DXF but does not want those geometries cut.

## Expected behavior
1. Distinguish cutting geometry from marking geometry.
2. Explain that merely drawing sketch geometry does not necessarily encode a laser-machine marking operation.
3. Treat layers/process attributes as a manufacturing-output concern.
4. Check the target laser/CAM workflow before claiming a universal shortcut.
5. Do not claim that a SolidWorks drawing entity automatically becomes a marking operation in every laser system.
6. Provide a practical export/check workflow.

# Core Skill Test Cases

## Bend analysis
2 mm sheet, 90° bend, no K-factor/tooling data → identify missing inputs; do not invent a universal K-factor.

## DXF marking
Sketch geometry should mark, not cut → classify as MARK; explain that DXF visibility does not encode process; verify CAM/layer convention.

## Turkish UI
User supplies Turkish SolidWorks screenshot → use visible labels as primary evidence and give Turkish path.

## Drawing review
Material field unreadable → report observation/uncertainty; do not assume material.

## Macro
Export active drawing to PDF → identify document context, code/outline, API/version caveats, and test step.

# Workflow — Drawing/CAD to Production Release

1. Confirm governing revision and source CAD.
2. Validate material/thickness/finish/BOM.
3. Verify flat pattern and bend-source assumptions.
4. Review DXF entities/layers/scale/duplicates/open contours.
5. Review critical dimensions, datums, GD&T and inspection method.
6. Review weld/fastener/hardware/assembly instructions.
7. Check supplier capability and special tooling.
8. Update mass/cost/quotation if design changed.
9. Run assumption/source/release gate.
10. Archive release record and change notes.

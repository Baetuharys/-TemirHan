# Workflow — New Sheet-Metal Enclosure

## A. Requirements
Environment, dimensions/envelope, payload, access/service, mounting, quantity, target IP/IK, thermal load, cable entry, finish, standards/customer spec.

## B. Architecture
Protected boundary, body/door/removable panels, mounting plate, hinges/locks, gasket path, gland plates, ventilation, grounding/bonding, lifting/mounting.

## C. Detailed design
Material/thickness, stiffening, bends/reliefs, weld strategy, fasteners/inserts, tool access, coating interfaces, gasket compression using supplier data.

## D. Verification
Interference, bend sequence, stack-up, drawing/GD&T, DXF, ingress paths, thermal, BOM/cost, assembly/service, test plan.

## E. Release
No IP guarantee without applicable product/test evidence. Close assumptions and source every project-critical numeric value.

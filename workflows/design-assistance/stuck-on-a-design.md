# Workflow — “I am stuck on this design”

1. **Intake:** What must it do? What is failing? What files/data exist?
2. **Freeze facts:** list supplied dimensions/material/environment/quantity and unresolved values.
3. **Diagnose:** requirement → geometry → process → assembly/service → verification.
4. **Route specialists:** only the domains involved.
5. **Generate options:** normally 2–4; include pros, risks and manufacturing impact.
6. **Quantify:** use calculators or source-backed data, never mental “typical” values for release-critical decisions.
7. **Visual/CAD step:** if needed, produce a sketch recipe, image-to-CAD draft, SolidWorks procedure or macro plan.
8. **Review:** drawing/GD&T/DFMA/IP/thermal/cost as applicable.
9. **Close uncertainty:** order missing measurements/tests/supplier questions by impact.
10. **Output:** “do this next” plus a reusable design-review record.

# Manufacturing Release Gate

```text
Engineering Intake
      ↓
CAD / SolidWorks
      ↓
Sheet Metal / Flat Pattern
      ↓
Technical Drawing
      ↓
DXF Release
      ↓
CAM: CUT / MARK
      ↓
Bending
      ↓
Welding / Fasteners
      ↓
Assembly
      ↓
Cost / Quotation
      ↓
Documentation
      ↓
Release
```

At every arrow, ask:
1. What information is transferred?
2. What has been verified?
3. What depends on a machine, CAM, supplier, customer, or standard?
4. What remains uncertain?
5. Can the next operation proceed without creating hidden assumptions?

# Release v0.9.0 — Case-Based Validation

## Goal
v0.9 shifts the library from skill inventory toward repeatable engineering validation.

## Added
- 10 realistic engineering cases.
- Case acceptance criteria.
- Case-specific failure modes.
- Case-driven regression workflow.
- Manufacturing release gate workflow.
- Integration regression test definition.

## Design principle
Cases are not canned answers. They are controlled scenarios that test whether the AI preserves the distinction between facts, calculations, assumptions, estimates, engineering practice, and source-dependent claims.

## Scope
The cases intentionally use the user's established project themes: 5754 aluminum mass verification, Turkish SolidWorks title blocks, DXF marking, four-corner welding, M4 fasteners, IP65 enclosure design, cost/quotation, and production release.

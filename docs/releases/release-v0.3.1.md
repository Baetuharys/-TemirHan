# Mechanical AI Library v0.3.1

## Purpose
Strengthen the first five production-oriented skills with integration test cases.

## Priority
The initial test suite focuses on the recurring workflow:

3D sheet-metal model → technical drawing → DXF → laser → marking/manufacturing

and on SolidWorks Turkish UI and macro generation.

## Quality rules
- Never present an estimate as an exact measurement.
- Never invent a standard value, K-factor, material property, menu path, or API behavior.
- Distinguish source-backed facts, engineering practice, assumptions, and uncertainty.
- Manufacturing output must be considered together with the target machine/CAM workflow.
- SolidWorks version/UI differences must be acknowledged when relevant.

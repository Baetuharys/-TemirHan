# Terminology Policy (Terim Politikası)

Terms are chosen in this order. The first rule that applies wins.

1. **SolidWorks interface labels** are copied exactly as the user's installed
   interface shows them. If the label has not been verified, mark it `[doğrulanmadı]`
   and give the English command name instead of guessing a Turkish one.
2. **Standard and drawing terms** follow the standard being cited (ISO / TS EN ISO / ASME).
3. **Established shop-floor terms** are used when the audience is production staff,
   even if a purer Turkish word exists, because the goal is that the person
   reading actually understands.
4. **Öztürkçe (etymologically Turkic) words** are preferred in explanatory text
   whenever they are already in real use and unambiguous
   (e.g. *açınım, büküm, kesim, kaynak, delik*). They are offered as the
   main word in prose, never as a replacement for rules 1 and 2.
5. **Coined words** that nobody in the trade uses are never introduced silently.
   If one is useful, it goes in the glossary as `öneri` next to the established term.

Why this order: a drawing or work order that uses a made-up word gets
mis-read on the shop floor, and a SolidWorks step that names a button that does
not exist wastes the user's time. Language care applies to prose, not to
labels and standards.

AI behavior: when writing Turkish prose, prefer rule-4 words; when quoting UI
or standards, follow rules 1–2; if two words compete, show the established
one first and the Öztürkçe one in parentheses once.

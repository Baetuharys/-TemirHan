# Licensing Decision

No repository-wide open-source license is selected automatically in this release. That is intentional: the final owner must decide whether the repository will be private/proprietary or released under an open-source license.

Before publishing publicly:
1. choose a license appropriate to your intended reuse;
2. confirm you have rights to all imported/salvaged source material;
3. keep copyrighted standards out of the repository unless licensed;
4. retain third-party notices/attribution where required.

Absence of a LICENSE file does **not** mean unrestricted reuse.

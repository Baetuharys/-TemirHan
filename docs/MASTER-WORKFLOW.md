# Master Engineering Workflow

## Trigger
Use this workflow when a task crosses more than one engineering domain or when the output will be released to manufacturing.

## Stage 1 — Intake
Capture:
- part / assembly identity;
- objective;
- material and thickness;
- manufacturing route;
- customer/project requirements;
- software/CAM context;
- required output format;
- critical dates or revision state.

## Stage 2 — Context audit
Classify every important input as provided fact, source-backed value, calculation, estimate, engineering practice, assumption, or unknown.

## Stage 3 — Specialist chain
Invoke only the relevant skills:
- sheet-metal bend analysis;
- flat-pattern workflow;
- manufacturability;
- technical drawing review;
- DXF release;
- weld/fastener review;
- enclosure/IP review;
- weight/cost analysis;
- documentation/quotation.

## Stage 4 — Cross-check
Check that upstream decisions do not conflict with downstream requirements. Examples:
- drawing thickness vs model thickness;
- flat pattern vs DXF;
- DXF geometry vs cut/mark process;
- bend feasibility vs tooling;
- weld/fastener selection vs access;
- IP requirement vs enclosure interfaces;
- quantity and process assumptions vs quotation.

## Stage 5 — Release gate
Output:
- release status;
- blockers;
- warnings;
- verified items;
- assumptions;
- required evidence;
- next action.

A release gate is not a declaration that manufacturing quality has been physically proven. It is a structured document-level readiness check based on available evidence.

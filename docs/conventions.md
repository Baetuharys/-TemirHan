# Conventions

- Use `kebab-case` for files and folders.
- Core content must remain AI/provider agnostic.
- ChatGPT and Claude-specific execution details belong under `adapters/`.
- Prompt files use YAML frontmatter.
- New tags should be coordinated through `catalog/taxonomy.md`.
- Do not place secrets, customer data, or non-shareable project data in the repository.
- New content should move through the lifecycle rather than jumping directly to packaged skills.

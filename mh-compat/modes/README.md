# Operating Modes

These modes turn the repository into a consistent operating system for engineering and market work.

## 1. intake
Extract objective, deliverable, constraints, inputs and missing information.

## 2. research
Collect current external evidence, prefer primary sources, record dates and source quality.

## 3. engineering
Perform calculations, design reasoning and manufacturability checks. Separate facts, calculations, assumptions and estimates.

## 4. verification
Challenge the result: units, formulas, standards, geometry, dependencies, source quality and downstream effects.

## 5. release
Apply release gates before a drawing/DXF/document/quotation is treated as ready.

## 6. market-intelligence
Research companies, projects, customers, suppliers, competitors and purchasing signals. Never turn an inferred relationship into a fact.

## 7. commercial
Convert technical scope and cost inputs into a traceable quotation/offer package.

## 8. audit
Review an existing AI answer or project output for unsupported claims, missing evidence, hidden assumptions and contradictions.

# Pattern: Door + Continuous Gasket Path

## Problem solved
Create a controllable sealing boundary around a serviceable door while keeping the gasket supported and compressible.

## Inputs required
Door size, material/thickness, hinge side and count, latch positions, gasket family/profile, target compression from the gasket supplier, enclosure orientation/environment, coating and welding route.

## Reasoning sequence
1. Draw the intended seal boundary as one closed loop.
2. Identify every interruption: corners, welds, hinges, latch penetrations, gland plates, hardware, seam transitions.
3. Check that the door and frame provide a repeatable compression land.
4. Check stiffness so latch force does not only compress locally.
5. Check corner continuity and gasket joining method.
6. Check drainage/water traps independently from the sealing path.
7. Prototype and inspect compression; use the applicable ingress test for any rating claim.

## Common failure modes
Local over-compression near latches; under-compression between latches; sharp corner bridging; weld bead under gasket; powder-coat buildup changing compression; door twist; compression set; hardware inside the sealing boundary.

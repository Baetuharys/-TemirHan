# Sheet-Metal Design Patterns

Reusable concepts for discussion and concept generation:
- return flange for edge stiffness;
- hat/channel stiffener;
- tab-and-slot self-location for welding/assembly;
- captive hardware / press-in fastener zones;
- removable service panel;
- bend relief and corner relief families;
- symmetry/common tooling to reduce setup count;
- common thickness/material strategy;
- datum-friendly locating features;
- poka-yoke asymmetry where mirrored assembly is a risk.

Patterns must be checked against real tooling, bend sequence, coating, assembly access and tolerance requirements.

# Turkish UI interaction map

## Response format
For every UI question, identify:
1. document type/workspace,
2. command or feature,
3. where it is accessed in the Turkish interface,
4. the relevant PropertyManager/options area,
5. the expected visual/result check.

## Evidence hierarchy
Use the user's screenshot and exact SolidWorks version as primary evidence. If either is missing, present version-dependent labels as such rather than fabricating a Turkish translation.

## Terminology rule
Preserve the English command name in parentheses when it prevents ambiguity, but do not replace the requested Turkish path with an English-only path.

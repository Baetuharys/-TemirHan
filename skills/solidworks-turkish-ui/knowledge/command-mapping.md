# Turkish UI Mapping Rules

The library must preserve the user's Turkish interface as the primary navigation language.

For an English command supplied by the user:
1. Identify the SolidWorks workspace.
2. Give the Turkish label/path only when verified or visible in supplied evidence.
3. Keep the English command in parentheses for disambiguation.
4. If exact wording varies by version, say so rather than fabricating a label.

Screenshots supplied by the user take precedence over generic remembered menu paths for that specific UI state.

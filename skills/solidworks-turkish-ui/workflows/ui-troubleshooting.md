# Turkish SolidWorks UI Troubleshooting

1. Identify document type: Part / Sheet Metal / Assembly / Drawing.
2. Identify active command/workspace.
3. Ask or infer only the minimum missing version/UI information.
4. Map the command to Turkish UI terminology.
5. Give the shortest sequence of clicks/locations.
6. If the command is unavailable, check feature prerequisites and workspace context.
7. Use the supplied screenshot as evidence when available.
8. End with a concrete verification step.

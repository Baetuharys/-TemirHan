# Question bank by task family

Ask only what changes the result.

| Family | Blocking questions |
|---|---|
| Sheet-metal geometry / bend | material and grade, thickness, inside bend radius, bend angle, K-factor source or shop bend table, dimension convention (inside/outside) |
| Weight | geometry source (CAD model, flat area, drawing), material + alloy/temper, density source, thickness actually used, what is included (coating, hardware) |
| Drawing review | standard in use, intended process, which sheet/revision, general-tolerance note present? |
| Enclosure / IP | target IP code, environment, mounting, openings list, parts' own ratings |
| DXF / laser | machine/CAM, thickness and material, layer-to-process mapping, marking vs cutting |
| SolidWorks help | SolidWorks version, document type (part/assembly/drawing), exact label text or screenshot |
| Macro | version, document type, configuration/property names, what must not change, sample file |
| Cost / quotation | quantity, supplied rates, price date and currency, VAT status, delivery and payment terms |
| Image measurement | reference object and its size, whether the photo is straight-on, purpose (estimate vs manufacturing) |
| Market research | region, product/sector, source date window, what counts as evidence |

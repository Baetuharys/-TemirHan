# Example: sheet-metal part estimate

Inputs:
- material grade and thickness;
- blank dimensions/area;
- purchased material price basis;
- cut/mark operations;
- bend count;
- weld/fastener operations;
- finish;
- labor and shop rates.

Process:
1. Calculate physical quantities first.
2. Apply the appropriate rate basis to each process.
3. Add explicit scrap/allowance assumptions.
4. Separate direct cost from markup/price if a quotation is requested.
5. Report which inputs dominate uncertainty.

# Manufacturing cost model

A cost estimate is a model with explicit inputs, not a single universal formula.

## Suggested structure
Material + cutting + marking + bending + joining + machining + finishing + assembly + inspection + scrap/rework allowance + overhead/other project costs.

## Sheet-metal drivers
- blank area/weight;
- material grade and purchase form;
- number of cuts/features;
- cut length and pierce count where available;
- marking length/feature count;
- bend count and setup changes;
- weld/fastener operations;
- finishing area;
- assembly time.

## Rules
- Keep supplier/shop rates separate from physical quantities.
- Label estimates and measured values separately.
- Do not reuse a machine rate from another shop without labeling it as an external assumption.
- Show the sensitivity of the total to high-uncertainty inputs when useful.

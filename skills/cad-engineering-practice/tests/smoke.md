# Smoke tests — CAD Engineering Practice

## Test 1
Supplier asks for the CAD file → recommends STEP + DXF + PDF with the same revision, asks which CAD/version they use.

## Test 2
Imported STEP must be flattened → checks thickness, units, rebuilds as native sheet metal; does not trust the flatten result blindly.

## Test 3
File named 'parça son hali (2) ÇALIŞMA.sldprt' → proposes a numbering scheme and warns about special characters.

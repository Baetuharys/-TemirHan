# Worked example — analysing a reference photo

**Input.** Photo of a bent bracket next to a ruler.
**Output.** (1) Visible parts and counts (1 bracket, 3 holes), (2) bends visible (2), (3) proportions (length:width ≈ 2:1 `[ESTIMATE]`), (4) invariants to preserve if edited, (5) what cannot be read (thickness, hole diameter).
For dimensions switch to `image-dimension-estimation` and require a reference object.

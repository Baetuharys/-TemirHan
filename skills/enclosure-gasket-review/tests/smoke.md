# Smoke tests — enclosure-gasket-review

A test passes only if the expected behaviour is present and nothing is invented.

1. Flat gasket glued to a lid with no compression stop → flags uncontrolled compression and proposes a hard stop or groove.
2. Gasket splice located at a corner → flags as leak risk; moves the splice to a straight edge or suggests a moulded/foam-in-place gasket.
3. User asks for the gasket compression percentage → gives no number from memory; asks for the gasket datasheet window.

# Project / Contract Research

For each project:
- project name
- owner
- contractor / EPC / OEM if documented
- supplier / subcontractor if documented
- country / location
- announced date
- award date if known
- current status
- scope
- value only when sourced
- relevance to the user's capability
- source references

Use the source's exact relationship language. Do not infer the winner or supplier from proximity alone.

# Weight-critical material research
1. Identify alloy/grade and temper/condition.
2. Identify product form if relevant.
3. Define required property: density, not merely a generic material name.
4. Collect multiple credible sources when the result is consequential.
5. Normalize units and compare differences.
6. Select a value only with a stated reason and source.
7. Recalculate weight and report sensitivity if density uncertainty materially affects the result.

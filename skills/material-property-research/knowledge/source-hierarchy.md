# Material source hierarchy

Use the strongest available source for the exact designation and condition:
1. Applicable material/product standard.
2. Manufacturer or mill certificate/datasheet for the exact product condition.
3. Recognized engineering database or handbook.
4. General reference value only when clearly labelled as approximate.

Never mix density from one designation with strength values from another condition without disclosure.
For weight-sensitive work, density and the exact material designation should be recorded explicitly in the calculation trace.

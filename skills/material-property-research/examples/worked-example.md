# Worked example: density for a weight check

**Request:** "5754 alüminyum yoğunluğu nedir? 5 kg'lık parçada kaç gram fark eder?"

1. Designation: EN AW-5754 (Al-Mg), temper not given -> density barely depends on temper, mechanical properties do.
2. Source class: no certificate supplied -> use nominal handbook value ~2660-2670 kg/m^3 (SOURCE-BACKED nominal; name the handbook when researching) and mark it for replacement by the supplier certificate.
3. Effect: 2660 vs 2700 kg/m^3 is 1.5%; on a 5 kg part that is about 75 g.
4. Output: value, label, source, and the statement that the exact value must come from the certificate before it is written on a shipping document.

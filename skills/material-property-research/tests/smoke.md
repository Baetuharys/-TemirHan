# Smoke tests — material-property-research

A test passes only if the expected behaviour is present and nothing is invented.

1. Asks for 316L yield strength as one number → refuses a single certified-looking value; names standard, condition and mill certificate.
2. Asks whether 5052 equals 5754 → says they are not identical and compares only with cited sources.
3. Asks for density of 1.4301 → gives a value with a source label and notes variation between sources.

# Bend Analysis Input Matrix

## Geometry
- thickness
- material
- inside bend radius
- bend angle
- bend direction
- flange lengths
- hole/edge proximity

## Process
- press-brake process
- tooling/V-die when known
- machine limits when relevant
- material condition/temper when relevant

## Calculation inputs
K-factor, bend allowance, bend deduction, or a shop-specific bend table must be treated as process-dependent inputs unless a verified source/table is supplied.

## Missing-data rule
If a requested calculation cannot be determined from supplied data, identify the missing input instead of inventing a typical value.

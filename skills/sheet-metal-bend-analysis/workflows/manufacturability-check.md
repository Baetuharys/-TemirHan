# Bend Manufacturability Check

1. Extract thickness, material, radius, angle, and flange dimensions.
2. Identify the manufacturing process and tooling assumptions.
3. Check whether the requested bend geometry is compatible with the stated process.
4. Check hole-to-bend and edge-to-bend relationships when holes/features exist.
5. Check tool access, collision, and likely bend sequence when geometry requires it.
6. Check whether the flat pattern depends on an unverified K-factor or bend table.
7. Separate calculated results from shop-specific values.
8. Return findings as: Confirmed / Assumed / Missing / Risk.

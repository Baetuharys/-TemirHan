# Controlled bend release
1. Lock material designation/condition and thickness.
2. Record inside radius, angle, flange dimensions and dimensioning convention.
3. Identify source of K-factor/BA/BD: validated shop data, bend table, or engineering assumption.
4. Calculate or inspect the flat pattern.
5. Check minimum flange, hole-to-bend and tooling access constraints.
6. Compare against a known production rule or sample where available.
7. Mark unresolved process-dependent values as release blockers rather than silently guessing.

# CAD Modelling Review: default workflow

## 1. State the design intent
Which dimensions drive the part and which are derived; which features must update together.

## 2. Check sketches and features
Fully defined sketches, sensible feature order, no unnecessary dependency chains, meaningful names, no suppressed leftovers.

## 3. Check references
External references and in-context relations are intended; broken or dangling references are listed.

## 4. Check configurations and properties
Configuration names are purposeful; custom properties filled; material assigned; mass properties plausible.

## 5. Check assemblies
Mates are sensible, no over-definition, interference checked where needed, large assemblies handled with lightweight or simplified representations.

## 6. Check exports
Formats fit the need: STEP for neutral 3D exchange (ISO 10303), DXF/DWG for flat 2D, native for editing; units and revision recorded.

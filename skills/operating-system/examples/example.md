# Worked example — routing a mixed request

**Request.** Kabin tasarımı IP65, 2 mm DKP, maliyet de çıkar, teklif de yaz.
**Routing.** `engineering-task-intake` → `ip-enclosure-design` → `enclosure-gasket-review` → `sheet-metal-manufacturability-check` → `cost-analysis` → `quotation-generator`.
**Contract.** Evidence labels on all numbers; no invented rates, customers or standards; open items listed at the end.

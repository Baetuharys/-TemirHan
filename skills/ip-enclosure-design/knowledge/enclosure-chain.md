# Enclosure design chain

The enclosure skill must treat an IP requirement as a system requirement, not as a property produced by a single gasket.

## Chain
IP requirement → enclosure architecture → mating surfaces → gasket strategy → cover/door compression → joints/fasteners → cable entries → ventilation/drainage → manufacturing → inspection/test.

## Required review
- Required ingress protection level and test context.
- Indoor/outdoor and environmental exposure.
- Door/cover interface continuity.
- Gasket path continuity and compression concept.
- Fastener spacing and local stiffness.
- Cable glands/connectors and unused openings.
- Vent/breather/drain components where applicable.
- Welded seams and penetrations.
- Paint/coating effects on mating surfaces.
- Planned verification/test method.

Never infer that a nominal IP class is achieved solely from the CAD geometry.

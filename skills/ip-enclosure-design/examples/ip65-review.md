# Example: preliminary IP enclosure review

Requirement: IP65 enclosure, sheet-metal construction.

Review order:
1. Confirm the required test/standard context rather than assuming a generic interpretation.
2. Trace every possible ingress path: door, seam, cable entry, ventilation, drain, fastener penetration.
3. Review gasket continuity and compression concept around the complete opening.
4. Review cover stiffness and fastener layout so the gasket concept is not defeated by local gaps.
5. Review manufacturing details such as corner joins, welds, coating and assembly sequence.
6. Define the verification/test plan.

The result is a risk review, not a claim that the enclosure passes IP65 without testing.

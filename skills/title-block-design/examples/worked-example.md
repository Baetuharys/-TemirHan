# Example: field strategy

| Field | Source type | Property / note | Status |
|---|---|---|---|
| Part number | custom property | user's property (e.g. the name used in the template) | confirm name |
| Description | custom property | same as above, wide cell | confirm name |
| Material | custom property or material data | the user's cut-list property | confirm |
| Thickness | sheet-metal value | cut-list/sheet-metal thickness property | confirm |
| Revision no./date | revision table | drawing revision table | ok |
| Main assembly | custom property | filled by workflow or macro; not guaranteed automatic | decide |

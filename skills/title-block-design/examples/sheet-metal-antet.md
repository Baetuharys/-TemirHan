# Example: simplified sheet-metal title block

A practical compact layout can reserve a larger description area while keeping a small revision table.

Recommended information grouping:
- Identity: drawing/part number + description
- Manufacturing: material + thickness + process note
- Revision: revision number + revision date + short change description
- Control: scale + units + general tolerance reference

If the main assembly field is required, treat it as a project/configuration property and verify how the organization maintains that relationship before promising automatic population.

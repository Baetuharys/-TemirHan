# Worked example — recolour a part without changing geometry

**Request.** Change the powder-coat colour of the cabinet in an existing photo to RAL 7035.
**Preserve.** geometry, door seams, hinge count, handle position, proportions, logo/text.
**Change.** surface colour only.
**Prompt.** Describe preserved elements first, then the single change; supply the original as the reference with the role "edit target".
**Verification.** Overlay original and result; check seams, hinges and text are unchanged.

# Marking release
1. Define the manufacturing intent for each geometry.
2. Separate CUT and MARK geometry using the actual CAM convention.
3. Export DXF with documented units/scale.
4. Reopen the exported file and inspect geometry/layers.
5. Load the DXF into the actual CAM and verify process assignment.
6. Check that marking entities are not assigned to cutting and that required cut contours remain complete.
7. Record the CAM/software version or shop convention when it affects interpretation.

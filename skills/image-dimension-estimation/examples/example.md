# Worked example — flat bracket with an A4 sheet

**Photo.** Flat bracket lying on an A4 sheet (210 × 297 mm), camera above, roughly perpendicular.
**Pixel measurements.** A4 long edge = 1485 px; bracket length = 640 px.

**Calculation.** `scale = 297/1485 = 0.200 mm/px` → `length = 640·0.200 = 128 mm`.
Pixel error ±3 px on each measurement → ≈ ±0.9 mm. Perspective and plane mismatch are larger: assume ±2–3 %.

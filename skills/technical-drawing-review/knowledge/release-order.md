# Drawing release order

Review in this order:
1. Identity: part number/name, revision, material, thickness, units, scale.
2. Geometry communication: views, sections, details, hidden/critical features.
3. Dimensions: functional/production dimensions, duplicates, contradictions.
4. Tolerances: general tolerance plus local tolerances.
5. GD&T: datum structure and feature control frames where needed.
6. Manufacturing notes: bend, weld, finish, hardware, marking, deburr.
7. Title block/revision traceability.
8. Downstream files: flat pattern/DXF/other released outputs if applicable.

A drawing can be visually complete yet still be unreleasable if its downstream manufacturing data is inconsistent.

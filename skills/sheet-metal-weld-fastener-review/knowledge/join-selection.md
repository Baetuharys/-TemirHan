# Sheet-metal joining review

Select joining method from load, access, sheet thickness, serviceability, appearance, corrosion, distortion, and manufacturing route.

## Weld review
Check:
- joint type and access;
- required weld location/extent;
- sequence and distortion risk;
- whether the drawing symbol communicates the intended weld;
- inspection requirement;
- downstream coating/finishing.

## Fastener review
Check:
- fastener type and material;
- sheet thickness and thread engagement where applicable;
- tool access;
- clearance and mating geometry;
- installation direction;
- service/removal requirement;
- whether a captive/self-clinching solution is required.

Do not select a specific fastener size from a drawing alone when load, thickness, material or supplier constraints are unknown.

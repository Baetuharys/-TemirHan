# Worked example — prompt for a sheet-metal enclosure concept

**Request.** Concept image of an outdoor IP65 control cabinet.
**Prompt structure.** Subject (wall-mounted sheet-metal control cabinet, hinged door, 4 cable glands at the bottom) → view (front three-quarter) → material/finish (light-grey powder coat) → setting (neutral studio) → negative constraints (no brand logos, no readable text, no extra doors).
**Rule.** The image is a concept; it must not be used as evidence of an IP rating or as a dimensioned drawing.

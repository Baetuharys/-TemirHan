# Function to characteristic

| Function | Typical characteristic | Datum need | Sheet-metal note |
|---|---|---|---|
| Hole pattern must fit a mating part | position (with datums) | yes | state which flange carries the datum |
| Door sealing face | flatness or profile of a surface | optional | gasket compression decides the value; free-state flatness is hard |
| Mounting face parallel to a base | parallelism | yes | depends on bend angle accuracy |
| Wall perpendicular to a base | perpendicularity / angularity | yes | bend angle tolerance |
| Cut-out outline in a panel | profile of a line/surface | yes | laser holds cut profile better than formed features |
| Whole-shape control | profile of a surface | yes | one callout replaces many dimensions |

Everything not toleranced: general tolerance note (ISO 2768-1 and -2 classes, ISO 13920 for welded parts).

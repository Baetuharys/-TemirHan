# Fabricator Capability Profile

> Fill from the actual shop. These values override generic heuristics.

## Identity / revision
Supplier/site · profile revision · date · owner.

## Materials
Available grades, thicknesses, stock sizes, certificate options.

## Laser / punch
Machine, working area, material/thickness range, hole/slot guidance, marking options, layer naming, kerf/CAM notes.

## Press brake
Machines, tonnage/length, tool library, preferred V openings, preferred inside radii, minimum flange by tool, special punches, bend table/K/BD source.

## Welding / joining
Processes, WPS coverage, fixture limits, stud/spot/insertion hardware.

## Finishing
Powder/paint/galvanizing suppliers, masking/grounding requirements, color/texture limitations.

## Inspection
Available gauges/CMM/fixtures, achievable and routinely controlled characteristics.

## File/release rules
DXF naming/layers/version, STEP/SolidWorks version, drawing/BOM requirements, first-article procedure.

# Engineering Case Library

v0.9 uses case-based validation to test whether the skills can handle realistic engineering tasks without inventing missing information.

Each case contains:
- `case.md` — scenario, inputs, required behavior, expected verification
- `expected-output.md` — acceptance criteria, not a canned engineering answer
- `failure-modes.md` — errors the AI must avoid

Cases intentionally separate known facts, calculations, assumptions, estimates, and source-dependent claims.

# Case: Technical Drawing Release Gate

## Scenario
A sheet-metal drawing is about to be released to production.

## Required skill chain
`technical-drawing-review` → `gdt-selection` → `title-block-design` → `sheet-metal-release-workflow`

## Required behavior
Review identity, revision, material, thickness, dimensions, tolerances, datums/GD&T where needed, weld/fastener notes, views/sections, and manufacturing downstream outputs.

Classify findings as:
- BLOCKER
- WARNING
- OBSERVATION

Do not invent missing dimensions or tolerances.
